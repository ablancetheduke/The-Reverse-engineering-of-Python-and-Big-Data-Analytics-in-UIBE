# 惠园教学APP 逆向工程

对"惠园教学" Electron 桌面客户端的安全审计与逆向分析。

## 项目结构

```
├── huangyuan_app/                    # v1.1.1 asar 解包源码
├── hyjx_1_1_0_asar/                  # v1.1.0 asar 解包源码
├── 惠园教学APP-安全审计报告.md        # 安全审计报告 (8项发现)
├── analyze_nsis.js                   # NSIS 安装包分析脚本
├── extract_nsis.js                   # NSIS 安装包提取脚本
├── jilu.md                           # 分析笔记
├── query_ranking.ps1                 # 排名查询脚本
├── ranking_raw.json                  # 排名接口返回示例
├── midterm_sample.json               # 期中提交示例 (已脱敏)
├── midterm_ranking.txt               # 期中排名 (已脱敏)
└── .gitignore
```

## 目标应用

- **名称**: 惠园教学APP
- **版本**: 1.1.0 / 1.1.1
- **框架**: Electron (Windows x64)
- **打包工具**: NSIS

## 主要发现

详见 `惠园教学APP-安全审计报告.md`，关键问题包括：

1. 🔴 教师工号硬编码在客户端源码
2. 🔴 教师端认证可离线绕过
3. 🔴 用户角色由客户端代码判定
4. 🟠 公开 API 接口无鉴权
5. 🟠 教师端设备绑定缺失
6. 🟡 客户端源码无混淆保护
7. 🟡 全部 API 端点完整暴露
